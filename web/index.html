Every request, five milliseconds.

  1. 01

    Intercept

    A reverse proxy sits in front of your app and inspects each request before it is forwarded.

  2. 02

    Detect

    34 IDPS signatures and an Isolation Forest anomaly score run against the normalized request.

  3. 03

    Correlate

    The SIEM stitches gateway, Suricata, and Wazuh events into multi-stage attack alerts.

  4. 04

    Contain

    The risk score drives throttling, bans, and blocks, and every action lands in a hash-chained audit log.

One score. Four signals.

ML Anomaly 30%
Rule Hits 30%
IP Reputation 20%
CVSS Impact 20%
risk = 100 × (0.3×ML + 0.3×rules + 0.2×rep + 0.2×CVSS/10)

Isolation Forest scores each IP's behavior over a 60-second window

Quick Start

PowerShell 
# Clone repository
git clone  sentinelgate
cd sentinelgate

# Setup environment
python -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt

# Configure
copy .env.example .env

# Run demo
.\demo.ps1

Requirements

  • Python 3.12+
  • 8 GB RAM (recommended)
  • Optional: Docker, Redis, nmap
